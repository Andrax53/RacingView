# RacingView
### Использованный фреймфорк tailwind
## О сайте
Разработка специализированного веб-сайта RacingView, посвященного новостям, анализу и контенту в области автоспорта. Сайт ориентирован на предоставление свежих новостей, результатов соревнований, интервью, фото- и видеогалерей, статистики, календарей событий и сообщества для обсуждений.
